Lector OCOM OCBS-2087 Configuración Auto-Sensing

Para que el lector se encienda solo al acercar un DNI o voucher (sin apretar el gatillo), apunta tu lector directamente a esta pantalla y escanea los códigos de la Página 11 del manual que se muestra abajo.

  1. (Opcional): Escanea el código Code Programming ON (arriba a la izquierda).
  2. Activar Auto-Sensing: Escanea el código que dice Auto Mode (abajo a la izquierda). El lector emitirá un pitido.
  3. (Opcional): Escanea Code Programming OFF (arriba a la derecha) para cerrar el modo de configuración.
💡 Nota sobre los modos:
• Auto Mode: Se enciende automáticamente al detectar variación de luz / movimiento al acercar un DNI o voucher.
• Continuous Mode: Mantiene la luz encendida permanentemente escaneando de continuo.
• Hand-held Mode: Vuelve al modo original de gatillo manual.
